📱 Installer CarWash Finder (Android) : contrairement aux logiciels Windows ci-dessus, c'est un fichier .apk à installer directement sur le téléphone. Une fois le fichier téléchargé, Android affichera peut-être un message du type « Source inconnue » ou « Installation bloquée » — c'est normal, l'appli n'étant pas distribuée via le Play Store. Il suffit d'autoriser l'installation depuis cette source, puis de lancer le fichier : l'appli est prête en quelques secondes.
